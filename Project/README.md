# Student Manager MERN Project

This project is a simple MERN-stack application for managing student information.

## Features

- Add students
- Display students
- Delete students
- Search students
- React Router navigation

## Technologies Used

- React
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

```text
backend/
frontend/
```

## How To Run Backend

Open terminal in the project folder:

```bash
npm install
npm run server
```

Backend runs on:

```text
http://localhost:5000
```

## How To Run Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

## Database

MongoDB is connected locally using Mongoose.
